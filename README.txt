SONU PORTFOLIO + ADMIN PANEL + VIDEO EDITOR

Included:
- index.html : portfolio website
- admin-panel.html : admin panel preview/UI
- integration/VideoEditor.tsx : video editor component
- integration/*.patch : integration patches for an existing Next.js/Supabase project

IMPORTANT:
This package is live-hostable as a static portfolio/admin UI, but the Admin Panel and VideoEditor patches are NOT a replacement for the existing Next.js/Supabase backend. To have uploads, database saving, authentication and Cloudinary storage work live, merge the integration into your existing project source and deploy that project.
